2026年4月2日、Shopify がベーシックプランでも B2B 機能を解放しました。以来、BtoB EC も Shopify で決まりだと言う人が増えています。

ただし、取引先ごとに細かく異なる契約単価（いわゆるマイ単価）を運用したい担当者の方は、飛びつく前に一度止まったほうがいいと思います。安く始めたはずが、取引先が増えたところで料金の壁か仕様の壁に当たる、という話をよく聞くからです。

この記事では Shopify、Bカート、EC-CUBE × [会員グループ価格管理アドオン](https://www.ec-cube.net/products/detail.php?product_id=2440) の 3 つを、価格管理という一点に絞って比べます。

---

## 1. 非Plus プランのカタログ 3 個制限

Shopify の下位プラン（Basic/Grow/Advanced）で B2B が解禁されましたが、そこには決定的な制限があります。

それは、**「有効化できるカタログ（価格表）は最大 3 つまで」** という点です。

### 「カタログ 3 個」で何ができるか？
- パターンA：全品 10% 引き（ブロンズ）
- パターンB：全品 20% 引き（シルバー）
- パターンC：全品 30% 引き（ゴールド）

ランク別の割引で回すなら 3 つで足ります。困るのは、A社とはこの価格、B社とはこの価格、と契約している場合です。**個別単価を 4 社以上に適用したい時点で、非Plus プランでは足りません。**

4 社目の個別単価が必要になった瞬間、残る選択肢は **Shopify Plus へのアップグレード** です。日本向けの公式価格で月額 368,000 円から。Basic の 4,850 円/月とは桁が 2 つ違います。

### EC-CUBE なら
会員グループ価格管理アドオンを導入した EC-CUBE なら、**グループ（カタログ）作成数は無制限** です。100 社あれば 100 通りの価格表を、追加の月額費用なしで管理し続けることができます。

---

## 2. Bカートの従量課金

BtoB 専用 SaaS の Bカートはよくできたサービスですが、料金が **商品数と会員数の上限** で決まります。

- ライトプラン（月額 9,800 円）: 商品 500・会員 50 まで
- プラン30（月額 29,800 円）: 商品 3,000・会員 3,000 まで
- プラン100（月額 49,800 円）: 商品 10,000・会員 10,000 まで
- プラン300（月額 79,800 円）: 商品 30,000・会員 30,000 まで

取引先が増えるほど月額固定費が上がるモデルです。初期費用も 80,000 円かかります。CSV 注文機能はプラン30 以上でしか使えないので、一括注文を入れたい時点で月額 29,800 円が下限になります。

### EC-CUBE なら
オープンソースである EC-CUBE は、**会員が 1 万人に増えても、商品が 3 万点に増えても、ライセンス料としての月額費用は 0 円** です。プラグインも一度導入すれば、規模の拡大に伴って価格が上がることはありません。

---

## 3. 基幹システム連携のスピード

BtoB EC で避けて通れないのが、基幹システム（ERP）との在庫・価格連携です。

### クラウドサービス（Shopify / Bカート）の課題
クラウド型サービスは、外部からのデータ更新を API 経由で行う必要があります。
API には「1分間に何回まで」という制限（レートリミット）があるため、**数万件の「取引先別単価テーブル」を毎日一括更新する** ような運用では、更新完了までに数時間を要したり、連携システム側の開発が複雑になったりすることがあります。

### EC-CUBE なら
自社サーバー（または専用クラウド）で運用する EC-CUBE は、API を介さずに DB へ直接アクセスするバッチ処理を組めます。大量の価格データをまとめて更新できるので、基幹システムとの相性がいいです。

## 徹底比較表：BtoB 価格管理の 3 大サービス

| 比較項目 | Shopify (非Plus) | Bカート | EC-CUBE (価格アドオン) |
|---|---|---|---|
| **個別価格表（カタログ）数** | **最大 3 つ** | 会員数上限まで | **無制限** |
| **月額ライセンス料** | 4,850 円〜（年払い 3,650 円〜） | 9,800 〜 79,800 円 | **0 円** |
| **初期費用** | 0 円 | 80,000 円 | 0 円 |
| **会員・商品数による制限** | なし | **あり（プラン依存）** | **なし** |
| **基幹システム連携** | API (レートリミットあり) | API (レートリミットあり) | **DB/バッチ** |
| **10社以上の個別単価管理** | **不可（Plus 必須・368,000 円〜）** | 可（会員数上限内） | **追加コストなしで可** |

EC-CUBE の 0 円はライセンス料の話で、サーバー費とアドオンの購入費は別にかかります。そこを含めても、取引先が増えたときに月額が跳ねないのが効いてきます。

## 結論：どのサービスを選ぶべきか？

### Shopify (非Plus) を選ぶべき人
- 取引先が数社、あるいは価格パターンが 3 つ以内のスモールスタート。
- デザイン性や海外販売（D2C 併用）を最優先したい。

### Bカートを選ぶべき人
- 自社でサーバー管理をしたくない。
- BtoB 特有の機能を設定だけで手軽に使い始めたい。

### EC-CUBE × 価格アドオンを選ぶべき人
- **取引先ごとに個別の契約単価（マイ単価）が 4 パターン以上ある。**
- **商品数や会員数が増えても月額固定費を上げたくない。**
- **基幹システムと大量の価格データを高速に連携させたい。**

「最初は Shopify Basic でいいと思ったが、カタログ上限で詰んだ」という相談は、実際によく来ます。取引先が 4 社目に増えるのは、たいてい事業がうまくいっているときです。そこで月額が 368,000 円に跳ねるのは、素直に痛い。

取引先ごとの単価が今後増えそうなら、**EC-CUBE × 会員グループ価格管理アドオン** も候補に入れて比べてみてください。
